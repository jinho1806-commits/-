================================================
   네이버웍스 메일 자동 발송 — 대시보드 연결판
================================================

대시보드(ffff-2df58.web.app)의 버튼을 누르면,
따로 올려둔 "메일 서버"가 네이버웍스로 메일을 보내는 구조예요.

  [대시보드 버튼] → [메일 서버(Render)] → [네이버웍스] → [받는 사람]

비밀번호는 "메일 서버" 안에만 있고, 대시보드에는 안 들어가요.


■ 폴더 안에 있는 것들
------------------------------------------------
  server.js               → 메일 서버 (Render에 올릴 것)
  package.json            → 필요한 부품 목록
  .env.example            → 비밀번호 적는 예시 파일
  대시보드에_붙여넣기.html  → 대시보드에 넣을 버튼 코드
  public/index.html       → (테스트용) 서버 단독 페이지


────────────────────────────────────────────────
 1단계. 네이버웍스 준비 (딱 한 번) ★★★ 중요 ★★★
────────────────────────────────────────────────
  [1-1] 관리자 허용 (이게 안 돼 있으면 SMTP 설정이 아예 안 보여요)
    - 네이버웍스 "관리자(Admin)"가 IMAP/SMTP 사용을 허용해야 해요.
    - 본인이 관리자가 아니면, 회사 관리자에게
      "메일 IMAP/SMTP 사용을 허용해주세요" 라고 요청하세요.

  [1-2] 내 계정에서 SMTP 켜기
    - 네이버웍스 메일 → 환경설정 → "POP3/IMAP" 메뉴
    - IMAP/SMTP 사용을 "사용함"으로 켜고 저장
    - 참고 가이드:
      guide.worksmobile.com/kr/mail/mail-guide/settings/pop3-imap-smtp/

  ※ 보내는 사람 주소는 반드시 "로그인한 그 계정"이어야 해요.
     다른 주소로는 못 보내요 (그래서 코드가 자동으로 같게 맞춰뒀어요).


────────────────────────────────────────────────
 2단계. 메일 서버를 Render에 올리기
────────────────────────────────────────────────
  ① 이 폴더를 GitHub에 올리기 (새 저장소 하나 만들어 push)
     ※ .env 파일은 절대 올리지 마세요! (비밀번호가 들어있음)

  ② Render → New → Web Service → 그 GitHub 저장소 선택
     - Build Command : npm install
     - Start Command : node server.js

  ③ Render의 "Environment" 탭에서 비밀번호 두 개를 등록:
       WORKS_USER = 내메일주소@회사도메인.com
       WORKS_PASS = 내비밀번호
     (= 따옴표 없이, 값만)

  ④ 배포가 끝나면 주소가 하나 생겨요.
       예) https://oa-mail.onrender.com
     이 주소를 복사해 두세요. (3단계에서 씀)


────────────────────────────────────────────────
 3단계. 대시보드에 버튼 붙이기
────────────────────────────────────────────────
  ① "대시보드에_붙여넣기.html" 파일을 메모장으로 열기

  ② 안에 있는 이 줄을 찾아서, 2단계 ④의 내 서버 주소로 바꾸기:
       const MAIL_SERVER = 'https://여기에-내-서버주소.onrender.com';
     (끝에 / 는 빼세요)

  ③ 그 파일 내용 전체를 복사해서,
     대시보드 HTML(=web.app에 올리는 원본 index.html)의
     원하는 위치에 붙여넣기

  ④ 대시보드를 다시 배포(firebase deploy 등)


────────────────────────────────────────────────
 메일 "내용" 바꾸기
────────────────────────────────────────────────
  - server.js 위쪽 MAIL_SUBJECT(제목)과 MAIL_HTML(본문)만 고치고
  - GitHub에 다시 push → Render가 자동으로 새로 배포해요


────────────────────────────────────────────────
 잘 안 될 때
────────────────────────────────────────────────
  · "sender address is unauthorized"
      → 1단계 SMTP가 안 켜졌거나, 비번이 틀렸거나,
        보내는 주소가 로그인 계정과 다를 때 나는 오류예요.
        1단계(관리자 허용 + SMTP 켜기)부터 다시 확인하세요.
  · "발송 실패"          → Render 비번(WORKS_USER/WORKS_PASS) 확인
  · 587 로 안 될 때       → server.js 의 transporter 설정을
        port: 465, secure: true 로 바꿔보세요.
  · "연결하지 못했어요"   → MAIL_SERVER 주소, Render 서버 켜짐 확인
  · CORS 오류            → server.js 의 ALLOWED 목록에
        대시보드 주소가 들어있는지 확인
  · Render 무료 플랜은 한동안 안 쓰면 잠들어서
    첫 발송이 30초쯤 늦을 수 있어요 (정상)


[참고] 내 컴퓨터에서 먼저 테스트하려면
  - .env.example 을 .env 로 바꾸고 비번 채우기
  - 폴더에서 CMD 열고:  npm install  →  node server.js
  - 크롬에서 http://localhost:3000 열어서 시험 발송
